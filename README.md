# HIV-1 Protease & Indinavir Molecular Docking Tutorial 🧬

An end-to-end, reproducible Google Colab tutorial for molecular docking and re-docking validation using modern computational biology libraries.

## 📌 Highlights
* **Target:** HIV-1 Protease Dimer (PDB ID: `1HSG`)
* **Ligand:** Indinavir (`MK1`)
* **Docking Engine:** AutoDock Vina v1.2.7
* **Preparation Stack:** RDKit (ETKDGv3), Meeko, PDB2PQR, OpenBabel
* **Validation:** Symmetry-corrected heavy-atom RMSD of **0.66 Å** against native crystal structure.
